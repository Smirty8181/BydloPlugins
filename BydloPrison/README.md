# BydloPrison

Заключение вместо кика: забаненный остаётся онлайн и смотрит от лица бессмертной свиньи.

## Команды

| Команда | Описание |
|---------|----------|
| `/prison ban <ник> <время> [причина]` | Заключить |
| `/заключить <ник> <время> [причина]` | То же |
| `/prison unban <ник>` | Освободить |
| `/prison info <ник>` | Инфо |
| `/prison list` | Список |
| `/prison setpos` | Точка зоны заключения (стоишь там) |
| `/prison reload` | Перезагрузка конфига |

## Время

`5с` `5м` `2ч` `3д` `30д` `навсегда`

Таймер идёт по реальному времени (оффлайн тоже).

## Права

- `bydloprison.ban` / `unban` / `info` / `list` / `setpos` / `reload`
- `bydloprison.bypass` — не попадает в заключение

## Интеграции

Soft-depend: voicechat, LibertyBans, LiteBans, AdvancedBan, BanManager, Essentials.

Для полной механики «не кикать» используй `/заключить` / `/prison ban`.
Внешние онлайн-баны могут перехватываться (`integrations.intercept-kicks`).
