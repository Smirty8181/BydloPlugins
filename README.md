# Кастомные плагины БыдлоЛенд

Набор собственных плагинов для Minecraft-сервера БыдлоЛенд. В репозитории размещены исходники и ресурсы плагинов; файлы мира, конфигурация сервера, сторонние плагины и готовые серверные данные сюда не входят.

## Состав набора

| Плагин | Версия | Назначение |
|---|---:|---|
| **BydloClasses** | 1.4.0 | Расы персонажей и связанные способности |
| **BydloCrafts** | 1.1.2 | Графический справочник рецептов |
| **BydloDiscs** | 1.0.2 | Персональные музыкальные пластинки |
| **BydloFishing** | 1.1.0 | Рыбалка с мини-игрой и собственным уловом |
| **BydloImplants** | 1.1.0 | Кибернетические импланты и улучшения |
| **BydloMage** | 1.0.0 | Магический класс и башня мага |
| **BydloPaint** | 1.0.0 | Создание и рисование на игровых полотнах |
| **BydloPrefixes** | 1.3.0 | Меню префиксов и интеграция с TAB/LuckPerms |
| **BydloPrison** | 1.0.1 | Система заключения игроков с командами `/prison` и `/заключить` |
| **BydloSmeltery** | 1.1.0 | Плавильня мифрила с интерфейсом обычной печи |
| **BydloTattoos** | 1.2.5 | Татуировки на скинах игроков |

Версии и описания соответствуют метаданным `plugin.yml` в исходниках. Для подробностей по командам и разрешениям смотри файлы `plugin.yml` и `config.yml` каждого плагина.

## Требования

- Paper API для Minecraft 1.21
- Java 21
- Дополнительные плагины для отдельных интеграций — указаны в `softdepend` или `depend` соответствующего `plugin.yml`

Часть плагинов использует API других плагинов при сборке. Такие зависимости нужно получить отдельно и положить в локальную папку `_build_libs`; для сборки BydloTattoos также требуется `plugins/SkinsRestorer.jar`. Сторонние JAR-файлы намеренно не включены в репозиторий.

## Сборка

Скрипты сборки добавлены для BydloFishing, BydloPrefixes, BydloPrison и BydloTattoos. После подготовки локальных API-зависимостей запусти PowerShell из папки нужного плагина:

```powershell
.\build.ps1
```

Скрипт создаёт JAR в локальной папке `plugins`. Для остальных плагинов в этом репозитории доступны исходники и ресурсы; готовые серверные сборки не включены.

## Структура

Каждая папка `Bydlo*` содержит `src/main/java` с исходным кодом и `src/main/resources` с метаданными, конфигурациями и ресурсами соответствующего плагина. Каталоги мира, журналы, серверные конфиги и файлы установленных сторонних плагинов не копировались.

Проект предназначен для демонстрации и развития пользовательских механик сервера БыдлоЛенд.
