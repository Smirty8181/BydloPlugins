## О проекте

**BydloPlugins** объединяет **14 собственных Paper-плагинов**, созданных для Minecraft-сервера БыдлоЛенд. Набор включает игровые механики для игроков, интерфейсы и инструменты для администрации, а также интеграции с отдельными плагинами сервера.

Зависимости подключаются только там, где они нужны: например, магический модуль расширяет `BydloClasses`, а фильтр системных сообщений требует `ProtocolLib`. Точный список обязательных и дополнительных интеграций находится в `plugin.yml` каждого проекта.

## Плагины

| Плагин | Возможности | Основные команды |

| [**BydloSmeltery**](./BydloSmeltery/) | Плавильня мифрила с интерфейсом привычной печи. Требует `CraftEngine`. | — |
| [**BydloScale**](./BydloScale/) | Изменение масштаба игрока через атрибут Minecraft `SCALE`. | `/scale <размер> [игрок]` |

### Инструменты сервера

| Плагин | Возможности | Основные команды |
|---|---|---|
| [**BydloMod**](./BydloMod/) | Инструменты модерации и администрации: муты, предупреждения, жалобы, обращения в поддержку, почта, Twitch-команды и меню персонала. | `/mute`, `/warn`, `/report`, `/support`, `/mail`, `/staff`, `/twitch` |
| [**BydloPrison**](./BydloPrison/) | Наказание с помещением игрока в заключение вместо немедленного кика; просмотр списка и освобождение. | `/заключить`, `/разбан`, `/prison` |
| [**BydloPrefixes**](./BydloPrefixes/) | Меню выдачи префиксов с необязательными интеграциями TAB, LuckPerms и PlaceholderAPI. | `/префикс` |
| [**BydloChatGuard**](./BydloChatGuard/) | Фильтрация некоторых системных предупреждений в чате. Требует `ProtocolLib`. | — |

Команды, алиасы, права и разрешения могут зависеть от конфигурации и версии плагина. Перед установкой проверь `plugin.yml` и `config.yml` соответствующего проекта.

## Совместимость и зависимости

- **Платформа:** Paper API с `api-version: 1.21`.
- **Java:** 21 для описанных Maven-сборок.
- **Обязательные связи между плагинами:** `BydloMage` требует `BydloClasses`; `BydloSmeltery` требует `CraftEngine`; `BydloChatGuard` требует `ProtocolLib`.
- **Дополнительные интеграции:** `softdepend` — необязательные плагины, с которыми проект умеет взаимодействовать при их наличии. Смотри `plugin.yml` внутри нужной папки.
- **Зависимости разработки:** API сторонних плагинов не включены. Их нужно установить отдельно в локальную среду сборки.

Указанная версия API не гарантирует совместимость с любой сборкой Paper или сторонним набором плагинов. Перед использованием проверь набор на тестовом сервере и сделай резервную копию данных.

## Установка на сервер

1. Проверь требования и обязательные зависимости выбранного плагина.
2. Собери нужный плагин или возьми JAR из своей доверенной сборки.
3. Помести его JAR в папку `plugins` сервера Paper.
4. Запусти сервер, проверь сообщения загрузки и настрой созданный конфиг.
5. Для плагинов с обязательными связями установи зависимости до запуска сервера.

В репозитории опубликованы **исходники и ресурсы**, готовые серверные JAR-файлы не включены.

## Сборка

### Maven

Maven-проекты: `BydloMod`, `BydloChatGuard` и `BydloScale`. Нужны Java 21 и Maven. Выполни команду в каталоге нужного плагина:

```powershell
mvn package
```

Для `BydloChatGuard` нужна зависимость `ProtocolLib` в серверной среде; Maven подключает её API как `provided`.

### Скрипты PowerShell

Для `BydloFishing`, `BydloPrefixes`, `BydloPrison` и `BydloTattoos` добавлены `build.ps1`. Например:

```powershell
cd .\BydloPrison
.\build.ps1
```

Скрипты используют локальный Paper API и дополнительные API плагинов из `_build_libs`; скрипт `BydloTattoos` также ожидает локальный `plugins/SkinsRestorer.jar`. Эти зависимости не публикуются в репозитории. Скрипты рассчитаны на Windows и создают JAR локально.

Для остальных плагинов исходники и ресурсы опубликованы, но самостоятельный воспроизводимый сценарий сборки в репозитории пока не настроен.
